# mattonazzo.github.io

> *This repository was born from a simple question:*
>
> **This repository was born from a simple question: If I'm going to learn HTML, CSS and JavaScript, why not learn Git and GitHub at the same time?**

This website is my personal portfolio and, at the same time, my learning playground.

Instead of following isolated tutorials, I decided to build a real project from scratch and let it evolve over time.
Every page, every refactoring and every commit represents something new I learned.

The project currently includes:

- a personal portfolio;

# Philosophy

The name **Mattonazzo** (= big brick) comes from a play on words, which informally describes a long, dense and demanding text.

That is exactly the spirit of this website.

I enjoy taking complex subjects apart, understanding them thoroughly and rebuilding them into something accessible without sacrificing technical accuracy.

---
# Accessibility

Accessibility has been a design goal since the beginning of this project.

The website uses the **OpenDyslexic** typeface, which was designed to support readers with dyslexia, and to make long-form technical content more comfortable to read.

Other accessibility choices include:

- semantic HTML whenever possible;
- responsive layouts;
- clear visual hierarchy;
- high-contrast interface elements.

Chi sono?

Classe 1988, ho ottenuto un diploma di Liceo Scientifico nel 2007.

Le mie esperienze professionali negli anni passate sono state piuttosto variegate:

  • Operatore di magazzino
  • Fattorino
  • Cameriere
  • Imbastitore di Sartoria
  • Apprendista elettricista in cantiere

Le mie competenze informatiche sono principalmente da autodidatta.

Sono sempre stato affascinato dai computer e da ciò che possono fare.

Tuttavia, solo di recente ho avuto l'opportunità di esplorare questo ambito della scienza, seguendo un corso universitario in Fondamenti di informatica.

Da allora ho continuato ad apprendere per conto mio.

Competenze Tecniche

Python

Python è il primo vero linguaggio di programmazione che posso dire di aver imparato, grazie a un corso universitario che ho frequentato.
Oltre alla programmazione in Python 3, il percorso mi ha permesso di assimilare concetti fondamentali come algoritmi, strutture dati e programmazione orientata agli oggetti (OOP). Ho concluso il corso con una valutazione di 25/30.

C

Ho imparato il linguaggio di programmazione C studiando i testi dei professori Facchinetti, Larizza e Rubini, e usando come punto di riferimento il celebre The C Programming Language di Kernighan e Ritchie.
Ho scritto la pagina di Wikipedia in italiano dedicata a scanf alla fine del 2025 e, ad oggi, ne rimango il principale autore.

Java

A marzo 2026 ho avuto l'opportunità di frequentare un corso di 140 ore su Java 25 organizzato tramite Adecco e Forma.Temp.
Il percorso ha previsto anche moduli introduttivi su Swing per le interfacce grafiche e sui database, con una breve introduzione a SQL. È stato inoltre incluso un modulo sulla sicurezza sul lavoro.

AppScript

Nell'uso di Google Sheets ho acquisito alcuni rudimenti di Google Apps Script per poter automatizzare alcune operazioni sui miei spreadsheets.

Shell

Usando Linux come sistema principale, ho sviluppato una buona familiarità con la shell e l'utilizzo della linea di comando.

HTML, CSS and JavaScript

Con l'obiettivo di costruire questo sito web portfolio, sto attualmente imparando le basi di HTML e CSS e nel mentre sto acquisendo confidenza con l'uso di git e GitHub.
Se hai già pensato che questo sito sembra uscito da un portale collegato al 2003, niente paura, internet è ancora salvo, sono io che sono solo all'inizio!

Progetti

Generatore Procedurale di Alberi

Un generatore procedurale e ricorsivo di alberi, sviluppato da zero con la libreria grafica Turtle di Python.Sfruttando angoli di ramificazione casuali, ricorsione profonda e modelli matematici probabilistici,l'algoritmo simula i pattern di crescita naturali per generare alberi dall'aspetto organico, completamente unici a ogni esecuzione.

Ordinamento visivo su Grafi

Un'applicazione interattiva in Python che visualizza l'ordinamento topologico su grafi aciclici diretti (DAG).Sviluppato utilizzando una libreria grafica personalizzata basata su Turtle, il motore dimostra in modo dinamicoil comportamento dello stack e gli aggiornamenti della lista di ordinamento passo dopo passo, rendendo intuitivida osservare e comprendere anche gli algoritmi su grafi più complessi.
